# Student Login Project

## Project Description
This is a simple Student Login and Details Management
project developed using HTML, Java Servlets, and Apache Tomcat.

## Technologies Used
- HTML
- Java
- Java Servlets
- Apache Tomcat 11
- Eclipse IDE

## Features
1. Student login page.
2. Student details form.
3. Display submitted student information.

## Purpose
This project was developed for learning Advanced Java
and understanding how HTML forms communicate with Java Servlets.
